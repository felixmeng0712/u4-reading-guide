# U4 带读网页与演讲稿（供参考）

这是我们组做 Unit 4 Reading A《Happiness, quantified》群文带读时用的网页和演讲稿，留给之后的小组参考。你们可以直接在它的基础上换成自己的课文。

## 里面有什么

| 位置 | 内容 |
| --- | --- |
| `dist/` | 带读网页：引子（读前讨论）、带读（逐段阅读＋词汇＋长难句＋结构）、写作三个模块 |
| `speeches/` | 三个人的演讲注意事项和完整英文演讲稿，外加一份 40 分钟的时间表 |
| `build_offline.py` | 把网页打包成一个可以双击打开的离线文件 |

## 怎么打开

```bash
python3 -m http.server 8766 --directory dist
```

然后用浏览器打开 `http://127.0.0.1:8766/`。不需要安装任何依赖。

## 这个仓库里没有的东西

- **课文原文。** 原文有版权，所以 `dist/paragraphs.js` 里每段只有占位文字和我们写的段意。把你们讲义上的原文逐段填进 `text` 字段，页面里的词汇下划线和长难句标记就会出现。
- **发音音频。** 四个单词的发音来自 Cambridge Dictionary，没有随仓库分发。来源记录在 `dist/audio/sources.json`；不放音频时点发音按钮会提示无法播放，其他功能不受影响。
- **作业提交系统。** 写作页的“提交作业”按钮现在指向一个占位地址，请改成你们自己的收作业方式（在 `dist/index.html` 里搜 `your-submission-page`）。

## 换成自己的课文要改哪里

1. `dist/paragraphs.js`：每段的原文 `text` 和段意 `summary`。
2. `dist/app.js` 开头的几个数据表：
   - `stages`：把全文分成几个阅读阶段，每个阶段的提问、结论和结构图要点。
   - `vocabulary`：每段要讲的词，格式是「原文中的写法、释义、用法、在文中的作用」。
   - `lexical`：每个词的原形和词性。
   - `sentences`：要分析的长难句。
3. `dist/index.html`：标题、读前讨论的选项、写作题目和范文。
4. 改完后运行 `python3 build_offline.py`，会生成离线版 `U4带读.html`（需要先放好原文和音频）。

`app.js` 里假设全文是 10 段、4 个阶段。段数不同的话，搜索代码里的 `9` 和 `3` 这两个边界值一并修改。

## 几条经验

- 老师的反馈：结构分析和读前问卷用英文呈现；最后要有一张完整的 text structure 图；写作素材要从原文里挖，范文要用上列出的表达。
- 带读主要是投影用，辅助文字不要小于 16px，灰色字要够深。
- 每个阶段都是「先提问，再读，再揭示结论」，不要一上来就把结论摆出来。
- 40 分钟讲 10 段很紧，写作更适合布置成课后作业。
- 网页里有一句标了「AI 改写」的练习长难句，不是原文，使用时要向同学说明。
